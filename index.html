Baixar para Windows

  1. Baixe e abra o instalador (não pede senha de administrador).
  2. Instale o Ghostscript (64 bits) se o PC ainda não tiver — é ele que lê os PDFs.
  3. Abra o programa pelo atalho. As próximas versões chegam sozinhas pelo próprio programa.
